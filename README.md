# NIPPOBRAZ — Site Institucional

Site institucional premium e mobile-first da Nippobraz, loja de produtos orientais em Belém–PA.

## Estrutura

Projeto estático em HTML, CSS e JavaScript, otimizado para publicação na Vercel.

## Desenvolvimento local

Abra o arquivo `index.html` no navegador ou use a extensão Live Server no VS Code.

## Conteúdo

A primeira versão apresenta a marca, categorias, história, localização, horários e canais de contato. Não inclui e-commerce.
